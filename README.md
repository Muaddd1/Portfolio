# Mouad Sehli — Frontend Developer Portfolio

Modern, minimal portfolio built with **React**, **TypeScript**, and **Tailwind CSS**.

**Live:** https://muad-portfolio.vercel.app

## Tech Stack

- React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React
- Vite

## Development

Requires **Node.js 20.19+ or 22.12+** (Vite 8's minimum).

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build    # production build
npm run preview  # serve the production build locally
npm run lint     # lint with oxlint
```
