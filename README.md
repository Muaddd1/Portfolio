# Mouad Sehli — Frontend Developer Portfolio

Modern, minimal portfolio built with **React**, **TypeScript**, and **Tailwind CSS**.

**Live:** https://muad-portfolio.vercel.app

## Tech Stack

- React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React
- Vite

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
